# Movie Portal (React + JSON Server)

## Run
```
npm install
npm run server      # terminal 1 -> API on http://localhost:3000
npm run dev         # terminal 2 -> website (open the link it shows)
```
Open **/movies** (or click "Movies" in the navbar). Click "View Details" on any card to see
the full details and to rate the movie.

Posters load from the internet (image.tmdb.org). If one can't load, a local poster from
public/posters is shown instead.
